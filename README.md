Представляем Систему управления успеваемостью – ваш цифровой помощник в образовательном процессе!

Возможности:
- Безопасный вход в систему
- Быстрый расчет успеваемости
- Автоматическое определение статуса (сдал/не сдал)
- Сохранение всех результатов в файл
- Просмотр истории успеваемости

Для кого:
- Преподаватели – автоматизация проверки знаний
- Студенты – контроль своей успеваемости
- Учебные заведения – цифровизация процессов
